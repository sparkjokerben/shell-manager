# smw Web UI 设计说明

## 简报

面向开发者的 Windows 持久终端管理台。使用者会让进程长期运行、在多个 shell 之间切换，并且
必须在不读说明书的情况下分清“断开”和“销毁”。设计对象是工具，不是通用 SaaS 仪表盘。

## 设计计划

### 色板（6 个核心色）

- **Petrol `#18282B`**：应用底色，深但不等于近黑。
- **Slate `#21363A`**：选中行、对话框和抬升控件。
- **Parchment `#E7E1D2`**：主文字，暖色以便与终端输出并置。
- **Brass `#D3A84E`**：主操作、附着/活跃信号、焦点陪伴色。
- **Oxide `#C3654D`**：只用于销毁语义：停止、错误与危险确认。
- **Ice `#8BB7BE`**：已连接状态和键盘焦点。

派生色：终端表面 `#102023`，分隔线 `#314A4E`，弱化文字 `#88A09B`。

### 字体角色

- **Bahnschrift**：字标、页面标题、会话名。Windows 自带的工业感展示字体。
- **Segoe UI Variable / Segoe UI**：正文、控件、对话框。
- **UbuntuMono Nerd Font / 苹方（PingFang SC）**：只用于终端；西文与 Nerd Font 图标用前者，中文用后者，不用等宽字体做装饰性小标签。

### 布局

```
┌ smw   持久 shell ────────────────────────── instance studio ┐
│ Sessions               │ build-main                        │
│ 3 sessions             │ instance studio      ■ Connected   │
│ [ + New session ]      │ Reconnect  Detach                  │
│ Refresh   every 2s     ├────────────────────────────────────┤
│ ─────────────────────  │ Windows PowerShell                 │
│ ▣ build-main  ∿ live   │ PS C:\work> cargo check            │
│ □ api-watch  attached  │     Checking shell-manager...      │
│ □ wsl-dev    idle      │                                    │
│                        ├────────────────────────────────────┤
│ Access token           │ Closing the tab or detaching...    │
└────────────────────────┴────────────────────────────────────┘
```

整体左对齐。侧栏是一条信号总线，不堆卡片；终端吃掉剩余空间，外框像仪表，而不是通用组件。

### 设计原则

1. **交换机，不是仪表盘。** 会话状态是总线上的插孔加信号轨迹，不是徽章网格。
2. **只留一个活跃信号。** 只有已附着会话显示波形；只有当前附着的会话在动，其余保持安静。
3. **断开和销毁必须看起来不同。** 断开是安静的；停止用 Oxide，并经过确认。
4. **终端就是产品。** 上下边框薄、信息有用，不抢终端内容。
5. **使用 Windows 自身的材料。** Bahnschrift、Segoe UI、UbuntuMono Nerd Font/苹方；不下载字体、不用图标库、不挂 CDN。

## 对照默认套路自检

第一反应是“近黑底 + 单一荧光绿”的终端界面，已改为 Petrol/Parchment/Brass/Oxide/Ice 体系。
布局刻意避开统一圆角卡片堆叠、全大写 eyebrow、用“·”拼 meta、按钮后加“→”，也没有装饰性编号
（会话不是序列）。记忆点是侧栏信号轨迹与终端顶部的状态色导轨，其余部分保持克制。

## 自评与据此做出的修改

- 实测对比度后抬高了弱化文字，并把半透明操作文字改成实色，避免可读性下降。
- 在动态轨迹下补了一条完整暗波形，避免移动亮段被误读成对勾。
- 把 Force 和 Stop 从“仅悬停可见”改为常驻但低音量，兼顾可发现性和键盘可达。
- 修掉 New session 按钮因 `width:100%` 加外边距而溢出侧栏 18px 的问题。
- 移动端侧栏关闭时从无障碍树隐藏，并补上焦点陷阱、Escape 关闭；危险确认默认聚焦 Cancel。
- 删除重复的强制接管说明，并在终端底栏明确写出“关闭标签页或断开只结束浏览器连接，shell 继续运行”。
